The **wOBA Scale** is the number which the run value [[./Linear Weights|linear weights]] are multiplied by to get the [[./wOBA|wOBA]] formula, which is scaled to OBP. This constant is used in [[wiki/wRAA|wRAA]] to convert a difference between two wOBAs to a run value.
